# ETS2 Phone Nav

Навігація, підказки поворотів і прилади **Euro Truck Simulator 2** на телефоні — для гри з кермом і видом
із кабіни без HUD. Працює на **macOS** (перевірено) і **Windows** (зібрано, але ще не перевірено на живій
грі — див. [статус](#статус)). Телефон нічого не встановлює: сторінка відкривається в Safari/Chrome через
домашню Wi-Fi.

*English summary: an ETS2/ATS telemetry plugin + a small local server that turns your phone into a
second-screen navigator — live map of the game world with your truck, a red route line to the job
destination, turn-by-turn hints, speed limit, cruise control, cargo info and alerts for fines and crashes.
macOS is tested; Windows builds but is untested in-game. See [docs/MACOS.md](docs/MACOS.md) and
[docs/WINDOWS.md](docs/WINDOWS.md).*

## Що вміє

- **Навігація:** карта світу гри з вашою вантажівкою (карта повертається за курсом, масштаб — від швидкості),
  **червона лінія маршруту** до компанії призначення, **підказки поворотів** («через 400 м праворуч»,
  кругові перехрестя з номером з'їзду, злиття, пором, прибуття), відстань і час до мети, запас до дедлайну.
- **Прилади:** швидкість, обмеження, круїз, передача, оберти, пальне й запас ходу, витрата, знос.
- **Вантаж:** звідки → куди з **гербами міст** (з Wikidata), маса, оплата, дедлайн, пошкодження.
- **Фінанси:** стан гаманця й кредиту — зі збережень гри (розшифровуються локально), між
  збереженнями баланс підправляється за доходами, штрафами й платними дорогами.
- **Сповіщення:** штраф (із причиною), аварія (на скільки пошкоджено вантажівку й вантаж),
  доставка, скасування, платна дорога.
- **Поворотники:** краї екрана блимають зеленим на всіх вкладках (аварійка — обидва).
- Панелі поверх карти можна **перетягувати пальцем** (окремо для альбомної й портретної орієнтації,
  подвійний дотик повертає на місце).
- Карту можна тягнути пальцем і масштабувати щипком; кнопка ◎ (або 20 с без дотиків) повертає до вантажівки.
- Перемикання вкладок кнопками внизу; км/год і км для ETS2, mph і милі для ATS.

## Як це влаштовано

```
Гра ── плагін (SCS Telemetry SDK) ──► файл спільної пам'яті
                                            │
              маршрутизатор ◄──── companion (Node) ──── Wi-Fi ───► телефон (браузер)
   (код навігатора truckermudgeon/maps)     │
                                    тайли карти, згенеровані з ваших файлів гри
```

| Тека | Що там |
|---|---|
| `plugin/` | плагін гри на C++ (SCS SDK 1.16): `.dylib` для macOS, `.dll` для Windows |
| `companion/` | сервер для телефона: читає дані гри, роздає сторінку, тайли й стан (Node ≥ 24, без залежностей) |
| `router/` | маршрутизатор: прокладає маршрут і рахує підказки кодом [truckermudgeon/maps](https://github.com/truckermudgeon/maps) |
| `web/` | сторінка для телефона (MapLibre GL + PMTiles) |
| `scripts/setup-mapdata.sh` | разова генерація даних карти з файлів гри (macOS / Linux / WSL) |
| `scripts/macos/`, `scripts/windows/` | встановлення плагіна, запуск, ярлик/застосунок |
| `docs/` | інструкції та [робочий журнал розробки](docs/SPEC.md) |

## Встановлення

- **macOS:** [docs/MACOS.md](docs/MACOS.md)
- **Windows:** [docs/WINDOWS.md](docs/WINDOWS.md)

Коротко: поставити плагін у гру → один раз згенерувати дані карти з файлів гри → запустити сервер →
відкрити на телефоні адресу, яку він покаже.

Вимоги: ETS2 1.61 (перевірено на 1.61.1.9s) і/або ATS 1.61 (дані перевірено на 1.61.3.18), Node.js 24+, телефон із сучасним браузером
(iPhone — iOS 15+, бо карті потрібен WebGL2), комп'ютер і телефон в одній Wi-Fi мережі.

## Статус

| | macOS | Windows |
|---|---|---|
| Плагін | ✅ перевірено в грі | ⚠️ збирається (MSVC у CI, mingw-w64), у грі ще не перевірено |
| Сервер і сторінка | ✅ | ⚠️ мав би працювати як є (Node), не перевірено |
| Дані карти | ✅ `setup-mapdata.sh` | ⚠️ через WSL (`tippecanoe` не має Windows-версії) |
| Маршрут і підказки | ✅ | ⚠️ маршрутизатор у WSL, не перевірено |
| ATS | ✅ дані карти, маршрут, герби/печатки, гаманець (перевірено на даних гри й імітаторі; у самій ATS — ще ні) | ⚠️ як і ETS2 |

Якщо пробуєте на Windows — напишіть в Issues, що спрацювало, а що ні.

## Права й обмеження

- Проєкт не пов'язаний із SCS Software. Euro Truck Simulator 2 і American Truck Simulator — торгові марки SCS Software.
- **Дані карти не входять до репозиторію й не публікуються**: вони похідні від файлів гри, тож кожен
  генерує їх локально зі своєї копії (`scripts/setup-mapdata.sh`).
- Після оновлення гри або DLC: перевстановіть плагін (Steam може його стерти) і перегенеруйте дані карти.
  Нова версія гри може зламати парсер карти — тоді доведеться чекати оновлення truckermudgeon/maps.
