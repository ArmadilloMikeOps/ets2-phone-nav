# Встановлення на macOS

Перевірено: macOS на Apple Silicon, ETS2 1.61.1.9s зі Steam, iPhone (Safari).
Гра на Mac — x86_64 (працює через Rosetta), тому й плагін збирається під x86_64.

## 1. Інструменти

```bash
xcode-select --install          # компілятор (якщо ще немає)
brew install node tippecanoe    # Node.js 24+ і генератор тайлів карти
```

## 2. Код

Або завантажте архів `…-macos.zip` з [Releases](../../releases) (плагін там уже зібраний), або:

```bash
git clone <адреса цього репозиторію> ets2-phone-nav
cd ets2-phone-nav
make -C plugin                  # plugin/build/ets2-phone-nav.dylib
```

## 3. Плагін у гру

```bash
scripts/macos/install-plugin.sh
```

Скрипт кладе `ets2-phone-nav.dylib` у `Euro Truck Simulator 2.app/Contents/MacOS/plugins/` (і в ATS, якщо стоїть).

- **«Operation not permitted»** — macOS захищає вміст `.app`. Дайте програмі Terminal дозвіл:
  *Системні параметри → Конфіденційність і безпека → Керування застосунками* → увімкнути Terminal, і запустіть скрипт ще раз.
- Гру треба **перезапустити**: плагіни вона підхоплює лише під час старту. У `~/Library/Application Support/Euro Truck Simulator 2/game.log.txt` з'явиться рядок `[ets2-phone-nav] ready`.
- Після оновлення гри Steam може перезаписати `.app` і стерти плагін — просто запустіть скрипт ще раз.
- Видалити: `scripts/macos/install-plugin.sh --uninstall`.

## 4. Дані карти (разово, ~5 хв)

```bash
scripts/setup-mapdata.sh
```

Скрипт клонує [truckermudgeon/maps](https://github.com/truckermudgeon/maps) у `.trucksim-maps/`, накладає виправлення
для ETS2 1.61, встановлює його залежності (кілька сотень МБ) і генерує з ваших файлів гри:
`mapdata/out/ets2/` (~300 МБ: дані карти, граф доріг) і `mapdata/out/tiles/` (~30 МБ тайлів).
Якщо гра не в стандартній теці Steam: `--game-dir "…/steamapps/common/Euro Truck Simulator 2"`.

Повторюйте після оновлення гри або купівлі нового DLC з картою.

## 5. Запуск

```bash
scripts/macos/start.sh
```

Або створіть застосунок на робочому столі з іконкою гри: `scripts/macos/make-app.sh` → `~/Desktop/ETS2 Phone Nav.app`
(при першому запуску дозвольте йому керувати Terminal).

Сервер надрукує адресу на кшталт `http://192.168.1.23:8420` — відкрийте її на телефоні.
Маршрутизатор стартує разом із сервером і вантажить дані ~15 с; до того червоної лінії не буде.

## 6. Телефон

- Відкрийте адресу в Safari → *Поділитися → На екран Додому*: сторінка відкриватиметься на весь екран, як застосунок.
- Щоб екран не гас: *Параметри → Екран і яскравість → Автоблокування → Ніколи* (на час гри).
  Сторінка відкривається через `http://`, а на iPhone утримання екрана сторінкою працює лише через HTTPS.

## Якщо щось не так

| Симптом | Що робити |
|---|---|
| «Гру не запущено або плагін не працює» | гра запущена? у `game.log.txt` є `[ets2-phone-nav] ready`? |
| «У грі стара версія плагіна» | `scripts/macos/install-plugin.sh`, перезапустити гру; або сервер старіший за плагін — перезапустіть сервер |
| Немає карти, «Немає тайлів…» | не виконано крок 4 |
| «Маршрутизатор не запущено» | немає `.trucksim-maps/` (крок 4) або дивіться `.logs/router.log` |
| Телефон не відкриває адресу | телефон і Mac в одній мережі? Брандмауер macOS: дозволити вхідні з'єднання для `node` |
