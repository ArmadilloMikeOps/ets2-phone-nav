# TruckSim Phone Nav — специфікація (v0.2, 26.10.2026)

> **Робочий журнал розробки** (жовтень 2026): рішення, заміри, знахідки. Шляхи й назви тек у ранніх розділах
> можуть бути застарілими — актуальна структура описана в [README](../README.md).

Навігація та прилади **ETS2 і ATS** на iPhone, для гри на **Mac**, з кермом і видом із кабіни без HUD.
Готових рішень під macOS немає (TruckNav, Funbit, SimHub розраховані на Windows), тож це власний проєкт.

---

## 1. Мета

Під час гри на телефоні, закріпленому біля керма, видно:
- швидкість, обмеження швидкості, круїз-контроль;
- скільки лишилося до точки призначення (відстань і час);
- **карту з позицією вантажівки** та, на пізнішому етапі, **маршрут**.

Обидві гри підтримуються **рівноцінно**: один плагін, один companion, один веб-клієнт. Яка гра запущена, визначається автоматично.

Встановлювати щось на телефон не треба: інтерфейс відкривається в Safari за адресою з домашньої Wi-Fi мережі.

### Рішення
- **Мережа:** лише домашня Wi-Fi. Режим без мережі (USB, точка доступу) не потрібен.
- **Ігри:** ETS2 і ATS.
- **Порядок:** спайки → прилади → карта → маршрут.

### Не мета (поки що)
- Керування грою з телефона.
- Мультиплеєр (TruckersMP).
- Підтримка Windows і Linux.
- Публікація в магазинах застосунків.
- Робота без Wi-Fi.

## 3. Архітектура

```
┌──────────────── Mac ───────────────────────────────┐
│                                                    │
│  ETS2 або ATS (x86_64, Rosetta)                    │
│   └─ plugins/trucknav.dylib  ← SCS Telemetry SDK   │
│        │ пише стан ~20 Гц + game_id                 │
│        ▼                                           │
│   /tmp/trucknav.shm  (mmap, фіксована структура)   │
│        │                                           │
│  companion (Node/TS, arm64)                        │
│   ├─ читає shm, нормалізує → JSON                  │
│   ├─ SSE  http://<mac-ip>:8420/events              │
│   └─ HTTP: PWA + тайли карти потрібної гри         │
└───────────────────────┬────────────────────────────┘
                        │ домашня Wi-Fi
                ┌───────▼────────┐
                │ iPhone         │
                │ Safari / PWA   │
                └────────────────┘
```

### 3.1 Плагін (`plugin/`, C)
- **Один `.dylib` для обох ігор.** При `scs_telemetry_init` читає `game_id` (`eut2` — ETS2, `ats` — ATS) і версію гри та пише їх у заголовок shm.
- Мінімальний: реєструє канали та події SDK і копіює значення в спільну пам'ять. **Без мережі, без алокацій у колбеках.** Що менше коду в процесі гри, то менший ризик її покласти.
- Збирається під **x86_64** (`-arch x86_64`), бо обидві гри x86_64.
- Канали v1: позиція у світі (x, z) і курс; швидкість; круїз; обмеження швидкості; паливо; передача; навігаційна дистанція й час (`truck.navigation.distance`, `.time`, `.speed.limit`); поточне завдання (місто/компанія відправлення й призначення, вантаж, дедлайн); пауза.
- SDK віддає значення в **м/с і метрах для обох ігор**. Одиниці відображення — справа клієнта.
- Протокол shm: `magic + version + seq` (seqlock), щоб companion не прочитав напівзаписаний кадр.
- Куди класти: `<Гра>.app/Contents/MacOS/plugins/` для кожної гри (readme SDK: «plugins subdirectory of the directory containing the game binary»). Підтвердити на ділі в S1.
- Мова: C++17 мінімальним підмножинням (заголовки SDK і приклади розраховані на C++). SDK 1.16 лежить у `plugin/vendor/scs_sdk/` (ліцензія MIT-подібна).
- **macOS App Management:** запис у бандл `.app` блокує захист macOS («Operation not permitted»). Програмі, з якої запускається `install-plugin.sh` (Terminal / Claude), потрібен дозвіл *Системні параметри → Конфіденційність і безпека → Керування застосунками*. Видає його користувач.

### 3.2 Companion (`companion/`, Node + TypeScript)
- Читає shm 20 разів на секунду, відправляє лише при зміні, із тротлінгом до ~10 Гц на клієнта.
- Транспорт — **Server-Sent Events** (`/events`), а не WebSocket: потік односторонній, у Safari є вбудоване перепідключення, і не треба жодних npm-залежностей. `/api/state` — поточний стан для налагодження.
- Зсуви полів shm бере з `plugin/build/layout.json`, який генерується з того ж X-макросу, що й структура в плагіні (`plugin/src/shm_layout.h`). Розкладка не дублюється руками.
- Стани: `no-game` (немає файлу), `stale` (seq не змінюється > 3 с — меню чи гра закрита), `paused`, `live`.
- За `game_id` вибирає набір карти (`mapdata/out/ets2/` або `mapdata/out/ats/`) і повідомляє клієнту, яка гра активна. Перемикання між іграми — без перезапуску.
- Віддає PWA, тайли та маршрут.
- Показує в терміналі QR-код з адресою для телефона.
- Слухає лише в локальній мережі, без автентифікації (v1). Порт налаштовується.

### 3.3 Веб-клієнт (`web/`, без збирання: HTML + CSS + JS)
- **Три вкладки, перемикаються кнопками внизу або свайпом; остання вкладка запам'ятовується:**
  - **Навігація:** відстань і час до мети, запас до дедлайну (зелений/червоний), місто й компанія призначення, знак обмеження, швидкість (червона при перевищенні), круїз, ігровий годинник, час до відпочинку. На етапі 2 сюди додається карта (MapLibre GL, вантажівка в центрі, поворот за курсом).
  - **Вантаж:** назва, звідки → куди, маса, оплата, відстань, до дедлайну, пошкодження, позначка спецзавдання.
  - **Прилади:** велика швидкість, обмеження, круїз, стоянкове гальмо, передача, оберти, пальне (смуга червона при попередженні), запас ходу, витрата, одометр, максимальний знос, модель вантажівки.
- Тост при доставці (дохід, XP) або скасуванні (штраф).
- Розкладка під iPhone в альбомній орієнтації (розміри від висоти екрана), портретна теж працює.
- **Одиниці за грою:** ETS2 — км/год і км; ATS — mph і милі. З можливістю перевизначити в налаштуваннях.
- Цільова платформа — **iPhone, Safari**:
  - Повний екран: Safari на iPhone не підтримує Fullscreen API для сторінок, тому додаємо сайт **«На екран Додому»** (`display: standalone` у manifest). Так зникають рядок адреси й панелі.
  - Екран не гасне: див. ризики (Wake Lock).
  - Альбомна орієнтація для кріплення біля керма; врахувати safe-area (виріз/Dynamic Island) через `env(safe-area-inset-*)`.
  - Тільки `http://` по локальній мережі. iOS при першому відкритті може спитати дозвіл на доступ до локальної мережі.
- Перепідключення WebSocket при обриві (iOS рве з'єднання, коли екран гасне або PWA йде у фон).
- Нічна тема автоматично, за ігровим часом.

### 3.4 Дані карти (`mapdata/`)
- Джерело: ігрові `.scs` кожної гри (`base_map.scs`, DLC-карти). Парсер: **[truckermudgeon/maps](https://github.com/truckermudgeon/maps)** (GPL-3, TypeScript), підтримує обидві гри.
- Результат **окремо для кожної гри**: векторні тайли (PMTiles) з дорогами, містами й компаніями, плюс граф доріг для маршрутизації.
- Генерується **локально** і перегенеровується після оновлення гри чи DLC. Ігрові файли в репозиторій не потрапляють.
- Перетворення координат гри (x, z) у проєкцію карти **різне для ETS2 і ATS**: брати з того ж проєкту.

#### Результати S2 (ETS2 1.61, ~3 хв їзди, завдання Reims / Kaarfor, 1452 км)
- Усі канали реєструються, «channel unavailable» немає. Подія `job` приходить з містом, компанією, вантажем (локалізована назва: «Мед») і `planned_km`.
- `truck.speed`, `cruise_control` — у реальних м/с світу; інтеграл швидкості (2583 м) збігся з пройденим шляхом за `world.placement` (2547 м).
- **`navigation.distance` — у «ігрових» метрах масштабу карти, а не у світових:** за той самий відрізок вона зменшилась на 49 677 м, тобто в **19,5 раза** більше за шлях у світі (масштаб ETS2 поза містами ≈ 1:19). Для UI це те, що треба: число збігається з кілометрами в ігровому GPS. Для маршрутизації по графу (етап 3) звіряти треба з урахуванням `local_scale` (в містах масштаб інший).
- `navigation.time` — секунди ігрового часу (1347 км / 69 825 с ≈ 69 км/год середня) — показувати як «ігровий час у дорозі».
- `navigation.speed.limit` — 80 / 70 км/год; **0 означає «немає даних/обмеження»** (бувало на стоянці) — у UI ховати, а не показувати «0».
- `heading` — у частках оберту (0…1), не в радіанах.

### Етап 1. MVP «Прилади» (корисне вже без карти) — **код готовий 26.10**
Три вкладки (див. 3.3). Перевірено в браузері на імітаторі (`scripts/fake_shm.py`, ETS2 і ATS): дані йдуть, одиниці правильні, стан «немає даних від гри» спрацьовує. **Лишилося перевірити з реальною грою і на iPhone.**

### Етап 2. Карта з позицією — **код готовий 26.10 (ETS2)**
Карта потрібної гри, вантажівка, курс, маркер точки призначення, масштаб залежно від швидкості.
- `web/vendor/`: MapLibre GL 5.24.0 + pmtiles 4.5.0 (BSD-3) — локально, щоб не залежати від CDN. Шрифти підписів — з `fonts.openmaptiles.org` (потрібен інтернет; вдома є).
- `web/map-style.js` — темний стиль за мотивами `GameMapStyle.tsx`: зони, префаби, дороги за `roadType`, пороми, кордони/вода з `world.pmtiles` (згенеровано tippecanoe з `generator/resources`), назви міст. Без POI-іконок.
- `web/projection.js` — порт `fromEts2CoordsToWgs84`/`fromAtsCoordsToWgs84` без proj4 (сферичний Ламберт); звірено з оригіналом: розбіжність ~1e-14°. Курс: `bearing = 360·(1 − heading)`.
- Плагін, формат shm **v2**: додано `job_{src,dst}_{city,company}_id`. Companion шукає точку призначення в `europe-companies.json` за `cityToken.token` (фолбек — центр міста) і віддає `dest_x/dest_y`; новий статус `old-plugin`, якщо в грі стара версія плагіна. Тайли — `/tiles/<ім'я>.pmtiles` з HTTP Range.
- Камера: «слідування» — вантажівка в нижній частині, карта повернута за курсом, zoom 15 (стоїмо) → 12 (90 км/год) ± кнопки; «огляд» — північ угорі, вантажівка + призначення з відступами під панелі. Карта неінтерактивна, щоб свайп гортав вкладки.
- Перевірено в браузері на імітаторі (`TRUCKNAV_SHM=/tmp/trucknav-fake.shm`, порт 8421). **Лишилося: перевірити з грою на iPhone.** Нюанс тестування: MapLibre 5 застосовує стиль у `requestAnimationFrame`, тож у прихованій вкладці браузера карта не з'являється.

### Етап 3. Маршрут — **червона лінія готова 26.10 (ETS2), перевірено на живій грі**
- SDK **не віддає геометрію маршруту** з ігрового GPS, лише дистанцію й час — будуємо самі.
- `router/router.ts` — окремий процес (порт 8430, лише localhost), **обгортка над кодом навігатора truckermudgeon/maps** (GPL-3; імпорт за абсолютними шляхами з клону, запуск `node --import tsx` з каталогу клону):
  - граф: `generator graph -m europe` → `mapdata/out/ets2-graph/europe-graph.json` (49 МБ, 89 598 вузлів, 16 с); `mapdata/out/ets2-nav/` — симлінки на розібрані дані + граф;
  - старт: `calculateFromNodeAndDirection` (на якій дорозі/префабі вантажівка і в який бік їде; курс SDK приймає як є);
  - фініш: `company.nodeUid` компанії `dst_city_id.dst_company_id` (якщо вузла немає в графі — найближчий вузол);
  - пошук: `findRoute(…, 'fastest')` (A*), з повтором у протилежному напрямку, як у навігаторі;
  - лінія: `getLineString` попарно по вузлах (однакові поспіль пропускаються, «погана» пара — прямим відрізком).
  - Пам'ять ~650 МБ, завантаження 3–14 с, маршрут Будапешт → Реймс ~0,4–0,7 с, ~2500 точок.
  - Звірка з грою: 61,2 км світу × 19 ≈ 1163 км проти 1136 км в ігровому GPS (≈2 %).
  - Нюанс: увімкнені **всі** DLC-guard'и — маршрут може піти через регіон DLC, якого немає (у користувача майже всі карти, тож поки не актуально).
- Companion: прокладає маршрут при новому призначенні або якщо вантажівка > 3 с далі за 600 «картографічних» м (≈30 м світу) від лінії; не частіше ніж раз на 5 с; лише в стані `live`. Рахує `route_progress` (найближчий відрізок, спершу у вікні біля попереднього) — клієнт малює лише залишок від вантажівки. Лінія — окремо `/api/route` (за `route_id`), щоб не ганяти тисячі точок 10 разів на секунду.
- Клієнт: шари `route-case` (#4a0809) + `route` (#e5252a) під підписами міст; рядок стану в панелі («прокладаю…», «маршрутизатор не запущено», помилка); огляд маршруту включає всю лінію.
- `scripts/start.sh` піднімає маршрутизатор у фоні (лог `.logs/router.log`) і гасить його разом із companion.
- Далі (опційно): підказки поворотів — у навігаторі є `route-step-builder`/`guidance.ts`, можна позичити.

### Етап 4. Зручності

## 8. Підказки поворотів і сповіщення (26.10)

### Підказки
- Маршрутизатор рахує маневри модулем `guidance.ts` навігатора (`calculateSteps`) і повертає `steps: [{dir, lonLat, exit?, text?}]`; `dir` — `BranchType` (0 прямо, 1–4 ліво, 11–14 право, 21–28 коло, 29 з'їзд з кола, −1 злиття, −3 прибуття, −4 пором). Прибуття додаємо самі.
- Дані кругових перехресть: `generator roundabouts -m europe -i … -g … -o mapdata/out/ets2-graph` (68 описів) → симлінк у `ets2-nav/`.
- Тексти на знаках (назви доріг/з'їздів) **порожні**: у розібраних даних ETS2 0 знаків з текстом — тому лише стрілка + відстань + опис маневру.
- Companion прив'язує маневри до лінії (метри від початку), рахує позицію вантажівки вздовж маршруту й віддає `maneuver: {dir, exit, text, dist, then_dir}` — наступний не-«прямо» маневр; при з'їзді з маршруту — `null`.
- Клієнт: картка вгорі по центру карти — SVG-стрілка, відстань (м/км або ft/mi), опис; < 400 м — зелене підсвічування.

### Сповіщення
- Плагін, shm **v3**: обробляє `player.fined` (`fine.offence` → `event_detail`, сума), `player.tollgate.paid`, `job.delivered`, `job.cancelled`.
- Окремої події «аварія» в SDK немає → companion ловить стрибок пошкодження: сума приростів по вузлах вантажівки + приріст пошкодження вантажу ≥ 0,2 % за кадр, збирає у вікні 1,5 с і видає «Аварія: вантажівка +X %, вантаж +Y %». Штраф `crash` (зіткнення з NPC) гра дає окремо.
- Клієнт: вікно по центру (червоне — штраф/аварія/скасування, зелене — доставка, жовте — платна дорога) + червоний спалах рамки екрана; закривається дотиком або саме за 6–9 с. Перше побачене після підключення сповіщення вважається історією і не показується.
- Перевірено на імітаторі `scripts/fake_shm.py --route --events` (їде справжнім маршрутом, підкидає штраф/аварію/платну дорогу).

### Старий iPad (A1432) — не підтримується
- A1432 = iPad mini 1 (2012), максимум iOS 9.3.5 / Safari 9: не виконує `<script type="module">` (тому сторінка була порожня), немає WebGL2 (MapLibre 5 потребує iOS 15+), `clamp()`, `env()`, CSS Grid, `gap` у flex.
- Спроба ES5-версії без карти була, але за рішенням користувача **відкочена** — підтримуємо лише сучасний iPhone.
- Урок: того ж разу карта на iPhone зникла не через ES5-версію, а через помилку в шарі обводки маршруту (`["*", interpolate, 1.5]` — MapLibre забороняє `zoom` не на верхньому рівні). Виправлено окремою шкалою `caseWidth`.

## 9. Розкладка, фінанси, герби (27.10)

- **Перетягування панелей** (`web/drag.js`): інфо, швидкість, маневр, кнопки карти. Поріг 8 px до початку
  перетягування й захоплення вказівника лише після нього — інакше кліки по кнопках `+ − ⤢` приходили б на панель.
  Позиції — у частках розміру карти, окремо `panels-landscape` / `panels-portrait` у localStorage; подвійний дотик — скинути.
  Стандартне місце маневру в альбомній орієнтації — внизу ліворуч (на iPhone 17 Pro, 874×402, верх зайнятий двома панелями).
- **Вкладка «Вантаж»:** жорстка сітка `auto-fit minmax(110px)` + `nowrap` давала накладання маси й оплати → плитки
  `flex-wrap` з `min-width: max-content`. Емодзі-іконки в заголовках, колонка «Фінанси» праворуч.
- **Гаманець і кредит** (`companion/save.ts`): SDK грошей не дає, тож читаємо найсвіжіший `game.sii`
  (Steam Cloud: `Steam/userdata/<акаунт>/227300/remote/profiles/*/save/*`, плюс локальні профілі).
  Формат `ScsC` = AES-256-CBC (публічний ключ SCS, як у SII_Decrypt) + zlib → `BSII` v3 (двійковий).
  Написано мінімальний розбір BSII: файл 918 720 байт прочитано рівно до кінця, 43 структури; беремо `bank`
  (`money_account`, `loan_limit`) і `bank_loan` (`amount`, `original_amount`). Також розуміє текстовий
  `SiiNunit` (`g_save_format "2"`). ~10 мс на файл; перечитується лише при новому збереженні.
  Між збереженнями до балансу додаються грошові події (доставка, скасування, штраф, платна дорога) — позначка «≈».
  Витрати на пальне/ремонт подіями SDK не приходять — їх видно лише з наступного збереження.
- **Герби** (`companion/coats.ts`): Wikidata EntitySearch за англійською назвою міста з даних гри
  + `P17 = країна` + `P94` (герб) → мініатюра з Commons. Поле `code` у `europe-countries.json` — **автомобільний** код
  (F, H, D), не ISO, тож країни зіставлено таблицею токен → QID (звірено з мітками Wikidata). Кеш (і промахи) —
  `mapdata/out/coats-<гра>.json`. Перевірено: Reims, Budapest, Vienna, Turin, Glasgow, İstanbul, Warsaw, Copenhagen, Linz…
